BROWN-AI™ Drug Discovery Platform

An integrated AI-first platform combining autonomous research agents with validated experimental workflows for accelerated cancer therapeutics development.

What is BROWN-AI™?

BROWN-AI™ is BrownBioTech's proprietary drug discovery platform that combines multi-model AI agents with continuous experimental validation. Built on years of cancer metabolism research, the platform enables rapid target identification, molecular design, and preclinical development—all accelerated by machine learning.

The platform integrates diverse data sources including TCGA, DepMap, and proprietary GIST laboratory data, enabling a closed-loop approach from target discovery to IND filing.

Core Platform

ARP™ — Autonomous Research Pipeline

Multi-model AI agents for continuous drug discovery

ARP™ is the orchestration layer that coordinates multiple AI agents to perform autonomous research. Each agent specializes in a specific task—literature analysis, multi-omics integration, molecular design—while the supervisor agent ensures coherent research direction.

The platform uses a research-Design-Test-Analyze loop that continuously refines hypotheses based on experimental results, mimicking the scientific method but at computational speed.

🤖
Multi-Model Routing

Dynamic model selection based on task complexity—Gemini Flash Lite for fast tasks, GLM-5 for complex reasoning, Nemotron for research synthesis.

🔄
Closed-Loop Validation

GIST wet lab integration enables rapid experimental validation of AI predictions, creating a continuous feedback loop.

📊
Knowledge Graph CoT

KG-CoT reasoning maintains coherent scientific narrative across thousands of literature sources and experimental results.

MoleculeForge™

Molecular Design

Diffusion-based molecular generation combined with GNN-guided similarity search. Generates novel drug-like compounds optimized for target binding and ADMET properties.

  • ✓ Diffusion model generation
  • ✓ E3GNN/Equiformer similarity search
  • ✓ Lipinski rule filtering
  • ✓ Scaffold hopping algorithms
  • ✓ Property optimization (MW, LogP, TPSA)
Powered by DrugPipe + Equiformer
⚗️

ATLAS-VS™

Virtual Screening

Self-verified virtual screening combining automated docking with AI-powered iterative repair. Based on ATLAS architecture for self-correcting molecular optimization.

  • ✓ QVina-W high-throughput docking
  • ✓ Self-generated test case verification
  • ✓ PR-CoT repair (multi-perspective)
  • ✓ Geometric Lens scoring
  • ✓ ADMET property prediction
Source: drugpipe_atlas.py
